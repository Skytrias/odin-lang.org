package main

import "core:fmt"

main :: proc() {
    points := [?]Vec3{
        {0, 0, 0},
        {1, 4, 9},
        {2, 8, 16},
    }

    for p, i in points {
        fmt.printf("%d: %.1f\n", i, length(p))
    }
}

Data layout

Struct-of-arrays without losing normal syntax.

Use SOA data when memory layout matters, while still indexing and accessing fields naturally.

Vector3 :: struct {x, y, z: f32}

positions: #soa[1024]Vector3

positions[0] = {1, 4, 9}
positions.x[1] = 2

assert(&positions[0].x == &positions.x[0])

Array programming

Work with vectors and fixed arrays directly.

Odin makes common numeric and SIMD-shaped code concise without giving up explicit types.

a := [3]f32{1, 2, 3}
b := [3]f32{5, 6, 7}

c := a * b
d := 1 + (c - a) / 2

fmt.println(d)

Implicit context

Control allocators and behavior at the call site.

The context system gives libraries a shared convention for allocation, logging, and runtime behavior.

context.allocator = arena_allocator()

data := make([]Vertex, vertex_count)
defer delete(data)

build_mesh(data)
